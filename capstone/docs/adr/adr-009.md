# ADR-009: Best-effort trace wire tap

Status: accepted

## Context
Diagnostics must explain causality without turning observer availability into a checkout dependency.

## Decision
Generate a hop ID before each provider request and propagate it in X-Causation-Id. Publish trace events without awaiting their confirms; the observer appends unique hops before ack. Retry and replay preserve the original correlation and explicit parent links.

## Alternatives considered
Awaiting trace storage gives stronger observability but makes tracing part of the critical path. Logging only plain text cannot reconstruct cross-service causality.

## Consequences
Observer downtime accumulates durable trace messages. A broker failure may lose a trace publication, so a complete trace is not guaranteed under infrastructure failure. Trace content is diagnostic data, never executable instruction.
