# ADR-010: Interrupted hand-rolled work needs operator review

Status: accepted

## Context
A process can die after a provider commits but before local success is recorded. Blindly rerunning forward work can produce an unwanted shipment.

## Decision
Persist owner and completed-step journal. On restart, processing records from an old owner become needs_attention unless waiting for a known broker retry. Expose confirmed steps and compensate only outstanding release/refund actions. Refuse compensation of live or terminal successful sagas.

## Alternatives considered
A timer alone mistakes slow live work for dead work. Automatic forward continuation cannot infer an ambiguous provider result. Temporal provides durable scheduling for the advanced mode.

## Consequences
The operator must inspect provider effects for an interrupted in-flight call. Compensation stops on its first failure and can be retried without redoing successful reversals. B2B never refunds payment. Temporal workflows own their recovery and reject this manual endpoint.
